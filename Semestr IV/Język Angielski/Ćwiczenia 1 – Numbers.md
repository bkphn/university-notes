## Big numbers
In English, we use the so-called short scale for numbers. This means that in the naming convention, we omit -*illiards* and stick to -*illions*:

| Name        | Value     |
| ----------- | --------- |
| Thousand    | $10^3$    |
| Million     | $10^6$    |
| Billion     | $10^9$    |
| Trillion    | $10^{12}$ |
| Quadrillion | $10^{15}$ |
| Quintillion | $10^{18}$ |
| ⋮           | ⋮         |

Even when dealing with plurals, we don't use the -*s* suffix when naming numbers. For example, $7,000,000$ is *seven million*, not *seven millions*.
## Fractions
A **cardinal number** is a number that expresses the quantity of a set. Cardinal numbers in English are: *One*, *Two*, *Three*, *Four*, *Five*, *Six*, …

An **ordinal number** is a number that indicates the order of elements. Ordinal numbers in English are: *First*, *Second*, *Third*, *Fourth*, *Fifth*, *Sixth*, …

When describing fractions, we use cardinal numbers for the numerator and ordinal numbers for the denominator. For example, $\frac{1}{3}$ is *one third*.

When the number $1$ appears in the numerator, we can replace the word *one* with *a*. For example, $\frac{1}{3}$ is *a third*.
## Decimals
In American notation, we use a period (called *point*) instead of a comma for the decimal part, so $1,7=1.7$. A comma can be used to separate parts of numbers, grouping digits into threes. For example $123456=123\,456=123,456$.

When pronouncing a decimal, remember that its decimal part is read digit by digit; for example, $341.341$ is *three hundred forty-one point three four one*.
## Zero
In mathematics, we often pronounce $0$ as *nought*. For example, $0.13$ is both *zero point one three* and *nought point one three*.
